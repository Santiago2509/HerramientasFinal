# Pendientes para los cuatro integrantes

El [README](../README.md#qué-falta-y-cómo-terminarlo) contiene los pasos y el reparto entre los cuatro integrantes. Esta lista sirve para comprobar los diez requisitos antes de entregar.

## Revisión de los diez requisitos

| Requisito | Solución o pendiente |
| --- | --- |
| 1. Precio promedio por m² | Promedio de los precios por m² de cada venta, en USD. |
| 2. Tipos de vivienda | Pendiente de consultar al profesor. El CSV carece de un campo que distinga casas y apartamentos. |
| 3. Mapa de precios | Mapa web por código postal, con zoom y puntos interactivos. Falta incorporar y comprobar el mapa de Power BI. |
| 4. Top 10 barrios | Ranking por código postal. Si el profesor exige barrios y permite otra fuente, hacen falta límites de barrios y una unión espacial con las coordenadas. |
| 5. Baños y habitaciones | Comparativas de precios medios con tamaños de grupo. El ANOVA compara tres grupos de habitaciones. |
| 6. Año de construcción | Precio medio observado en las ventas de 2014–2015 para cada año de construcción. |
| 7. Predicción | Regresión con ocho variables, comparación en un conjunto de prueba y comando de estimación. |
| 8. Superficie y valor | Dispersión y correlación de Pearson. |
| 9. Vista al mar | Comparativa por frente al agua. Para afirmar que es vista al mar haría falta un campo o una fuente que lo distinga. |
| 10. Segmentación de precios | Seis bandas en USD con límites inferiores inclusivos y superiores exclusivos. |

Para la revisión final, abran el .pbix y la página, prueben los filtros y comparen los valores con la sección de referencia de la [metodología](METODOLOGIA.md#referencias-para-validar-power-bi).
