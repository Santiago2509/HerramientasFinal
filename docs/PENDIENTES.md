# Pendientes para los cuatro integrantes

| Responsable | Entrega | Cómo comprobarla |
| --- | --- | --- |
| Integrante 1 | Armar y entregar el archivo .pbix a partir de la guía y las medidas DAX | Revisar tipos de datos, relaciones, filtros y que las tarjetas coincidan con la web sin filtros. |
| Integrante 2 | Validar el mapa, el ranking y la publicación de la web para la clase | Probarlo en móvil y escritorio. Confirmar el acceso del profesor y el formato de entrega que pide. |
| Integrante 3 | Completar la interpretación estadística | Añadir comparaciones por pares si las exige la rúbrica, interpretar el tamaño de efecto y comprobar el modelo con una partición temporal o validación cruzada agrupada. |
| Integrante 4 | Resolver el requisito de casas y apartamentos y preparar el informe | Consultar si se admite otra fuente y, si se une, medir su cobertura. Documentar la decisión, preparar la presentación y comprobar los diez requisitos. |

## Cobertura inicial

| Requisito | Solución o pendiente |
| --- | --- |
| 1. Precio promedio por m² | Promedio de los precios por m² de cada venta, en USD. |
| 2. Tipos de vivienda | Pendiente. El CSV carece del campo que distinga casas y apartamentos. |
| 3. Mapa de precios | Mapa web por código postal, con zoom y puntos interactivos. Falta incorporar y comprobar el mapa de Power BI. |
| 4. Top 10 barrios | Ranking inicial por código postal. Un ranking de barrios requiere límites oficiales de barrios y una unión espacial con las coordenadas. |
| 5. Baños y habitaciones | Comparativas de precios medios con tamaños de grupo. El ANOVA compara tres grupos de habitaciones. |
| 6. Año de construcción | Precio medio observado en las ventas de 2014–2015 para cada año de construcción. |
| 7. Predicción | Regresión con ocho variables, comparación en un conjunto de prueba y comando de estimación. |
| 8. Superficie y valor | Dispersión y correlación de Pearson. |
| 9. Vista al mar | Comparativa mediante frente al agua. El dataset no indica si ese cuerpo de agua es mar, lago u otro. |
| 10. Segmentación de precios | Seis bandas en USD con límites inferiores inclusivos y superiores exclusivos. |

Compartir el enlace de la web con los integrantes solo cuando la modalidad de acceso se haya confirmado. El archivo de Power BI y la página web se pueden entregar juntos.
